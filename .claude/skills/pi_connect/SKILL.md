# Raspberry Pi робота (MAZE2027)

Pi 5, пользователь `madness`, код в `~/maze` (плоско), venv `~/maze/venv` (Python **3.11**).
Лидар `/dev/ttyAMA3`, ESP — `/dev/serial0` @ 921600. `sudo` требует пароль.

## 1. Адрес

IP меняется от сети к сети (был `192.168.78.26`, `10.197.31.57`, `10.46.204.57`). По порядку:
1. Адрес, который пользователь назвал в этой сессии.
2. Дисплей сзади робота после загрузки показывает IP (`maze-oled.service`) — спросить, что там.
3. С Мака: `arp -a | grep -i 2c:cf:67` (MAC-префикс Pi); пусто — пинг подсети и снова `arp`.
4. Иначе спросить у пользователя.

Записи в `~/.ssh/config` с `User raspberry` — мёртвые, не использовать.

## 2. Связь — только ключом

```bash
ssh -o BatchMode=yes -o ConnectTimeout=5 madness@<IP> 'hostname && uptime'
```

- **Никогда** не передавать пароль (`sshpass`, пароль в команде) — ключ установлен.
- `Permission denied` → ключа нет: пользователь сам выполняет `ssh-copy-id -i ~/.ssh/id_ed25519.pub madness@<IP>`.
- `REMOTE HOST IDENTIFICATION HAS CHANGED` → Pi переустанавливали; предложить `ssh-keygen -R <IP>`, сам не удалять.
- Таймаут → Pi выключена или в другой сети. Сказать и ждать, не перебирать адреса бесконечно.

## 3. Заливка

Порядок, не пропускать:
1. Сначала проверка локально — **REQUIRED SUB-SKILL:** maze-verify.
2. Какие файлы: `pi/X` → `~/maze/X` (на Pi всё лежит плоско в `~/maze/`, в том числе `pi/victim_detect.py` и `pi/map_web.py`); веб пульта — `pi/dash/*`; модели — `~/maze/models/` (см. yolo-retrain).
3. Скрипт делает сверку md5, `.bak`, копирование, `py_compile` в venv и откат, если не компилируется:

```bash
python3 .claude/skills/pi_connect/deploy.py madness@<IP> pi/nav.py pi/walls.py --dry-run
python3 .claude/skills/pi_connect/deploy.py madness@<IP> pi/nav.py pi/walls.py
```

- Код 2 = на Pi правка, которой нет в git (пользователь правил прямо на Pi). Забрать файл, показать разницу, спросить. `--force` — только с согласия.
- Предупреждение «запущен nav.py» — спросить, можно ли заливать сейчас.
- Поменялся протокол ESP↔Pi (`robot_link.h`) → залить и прошивку (esp-flash), иначе `telem.py` покажет 0 Гц.
- Полная сверка всего `~/maze` с репозиторием: `~/maze/venv/bin/python ~/maze/bringup.py --hashes`.

## 4. Команды для пользователя

Пользователь вставляет команды в уже открытую SSH-сессию на Pi — давать **без обёртки ssh**, одна команда — один блок `bash`. Заезд всегда с `-u` и логом:

```bash
~/maze/venv/bin/python -u ~/maze/nav.py --no-color 2>&1 | tee ~/maze/run_$(date +%H%M).log
```

Флаги `nav.py`: `N` (число) — потолок разведанных клеток (по умолчанию 300; «только 6 плиток» → `6`), `--no-color` без датчика цвета, `--no-vision` без камер, `--no-web` без страниц, `--red-checkpoint` красная = чекпоинт (тренировка). Модель: `MAZE_MODEL=C3` перед командой. Старт — кнопка GPIO27 (левая рука) или GPIO25 (правая).

Если пользователь просит «команду для Мака» — тогда `scp`/`ssh` с Мака, тоже одним блоком.

## 5. Проверки на Pi

`telem.py`, `servo_test.py` и `nav.py` делят один порт — перед ними остановить `nav.py`.

| Что | Команда (`~/maze/venv/bin/python ~/maze/…`) |
|---|---|
| Всё ли на месте после включения | `bringup.py` |
| Телеметрия ESP, кнопки, концевики | `telem.py` |
| Датчик цвета, насыщение | `color.py 3` |
| Калибровка плиток (страница :8002, кнопка GPIO27) | `tile_calib.py` |
| Лидар в браузере (:8080) / сырой скан | `ld19_web.py` / `raw_scan.py -n 30` |
| Детектор «сняли с поля» | `lift.py` |
| Серва дозатора | `servo_test.py` |
| Метки на камерах, цвета колец (:8000, /tune) | `victim_web.py` |

Страницы во время заезда: карта `:8001`, пульт `:8888`. Логи: `~/maze/run_*.log`, `map_web.log`, `dash_web.log`, `wall_debug.log`, `nav_hup.log`.

## 6. Чего не делать самому

- `sudo`, `apt`, `/boot/firmware/config.txt`, перезагрузка, `nmcli` — отдать команду пользователю.
- `pip install` в venv — только `--no-deps`: свежие numpy/opencv ломают камеры (picamera2 собрана под системный numpy 1.x). После — проверить `from picamera2 import Picamera2`.
- Долгие процессы — с `timeout` или в фоне; после теста `pgrep -af python` и остановить свои.
- Удалять файлы на Pi — только с согласия.
