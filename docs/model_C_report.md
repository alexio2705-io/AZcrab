# Модель C: ложные метки и ночь 2026-10-12

Коротко: модель C (`maze_v26n_C.pt`) больше не называет приманки жертвами
(17.8% → 0 из 1244) и находит настоящие метки лучше модели B. Код на Pi уже
понимает её новые классы; по умолчанию в коде пока стоит B — C включается
переменной окружения, когда файлы модели лежат на Pi. Ночью же — три правки
`nav.py` по симулятору (шаг вбок у препятствия, повторные кадры, голосование
по типу). Ничего не закоммичено: автоматический режим запретил коммиты, всё
лежит в рабочей копии (ветка `victim-watch`).

## 1. Почему B ошибалась на соревнованиях

B обучена только на Φ/Ψ/Ω и когнитивных метках. Ни одной ложной метки в
датасете не было (класс `f` чужого датасета выкидывался, кадры с ним стали
фоном). Модели некуда отнести «букву, но не нашу» — она выбирает ближайший
известный класс, и уверенность при этом не калибрована: поднимать порог
бесполезно.

Замер на 1244 приманках (порог 0.45, как на роботе):

| приманки | B называет жертвой |
|---|---|
| два чужих RCJ-датасета H/S/U (в обучении не было) | 39.8% и 19.6% |
| синтетика (буквы/цифры/символы на наших стенах) | 10.0% |
| всего | **17.8%** |

Чаще всего: S → Φ (52), S → Ω (32), буквы → Ω (25), H → Ψ (17), U → Ω (13).

## 2. Что сделано

**Датасет `~/maze_dataset/ds_v2`** (`build_ds_v2.py`): 15 535 кадров train, 991 val, 8 классов —
прежние `cognetive omega phi psi` (индексы 0–3 те же) + `H S U letter`.

| источник | что | куда |
|---|---|---|
| `ds_ext` (свои + robocup-ffq6y) | Φ/Ψ/Ω/цели | train/val как было |
| `synth_letters.py` | 3052 кадра: на наши стены вклеены буквы латиницы, кириллицы, греческого, цифры, символы (Arial/Verdana/Tahoma/Helvetica, любой поворот, перспектива, смаз). Без Φ Ψ Ω Ф Ѱ и без Ø (повёрнутая Ø — вылитая Φ) | train/val |
| Roboflow `rcj-27-symbols` | Φ/Ψ/Ω/цели регламента 2027, класс `f` (мусорные рамки) выброшен | train |
| Roboflow `greek-wo0gb` | Φ/Ψ/Ω на стенах + неразмеченные приманки рядом (8, Ξ, Λ, S, Y) | train |
| `rrrrr-9`, `robot-2`, `h-s-u-final`, `hsu-pqv3n` | старые RCJ H/S/U (+ «прочие» N, Y, B, P, V, Z) | train |
| `alphabet-xjdmz`, `letters-1.1k` | цветные/шрифтовые буквы, цифры, стрелки | train |
| `aquila/rcj`, `gu56a/hsu` | RCJ H/S/U | **только val** — честная проверка на незнакомых приманках |

Отброшено после просмотра: вертолётные площадки, коробки HHH, скриншоты игры
(`u-s`), номера машин, язык жестов, рукописная кириллица, кадры симулятора
Erebus, приватная лицензия. Готовой печатной кириллицы на Roboflow нет —
поэтому синтетика.

**Обучение** (`train_v2.py`): старт с весов B, 60 эпох, `degrees=45` (по
регламенту метки бывают повёрнуты), 3.1 ч на M4 Pro. Лучшие веса — эпоха 51.

**Код на Pi** (не закоммичено):
- `pi/watch_logic.py` — `victim_boxes()`: из выдачи YOLO только жертвы; рамка
  жертвы выкидывается и тогда, когда на том же месте увереннее лежит приманка.
  Нужно потому, что голова YOLO26 берёт лучшие пары «якорь × класс», и одна U
  приходит и как `U 0.9`, и как `omega 0.5` — фильтра по классу мало. Тесты в
  `pi/tests/test_watch_logic.py` (5 новых).
- `victim_detect.py` (`_best`) и `pi/watch_proc.py` — через неё. Для модели B
  ничего не меняется. Кадры с приманками наблюдатель по-прежнему сохраняет в
  `~/maze/detections` — пригодятся для дообучения.

## 3. Результат

Val с исправленной разметкой (см. п. 4), порог 0.45:

| | B | **C** |
|---|---|---|
| приманки → жертва, всего (1244) | 17.8% | **0.0%** |
| незнакомые RCJ H/S/U (463) | 31% | **0.0%** |
| ложная жертва «из ничего» | 0 (11 при 0.25) | **0 (и при 0.25)** |
| Φ найдено | 83.6% | **88.4%** |
| Ω найдено | 88.7% | **92.7%** |
| Ψ найдено | 95.3% | **98.7%** |
| когнитивные цели | 98.7% | **100%** |

На своих «чистых» кадрах (без синтетики) B и C почти равны; выигрыш C — на
смазанных/повёрнутых кадрах и, главное, на приманках. Ни одной приманки C не
назвала жертвой и при быстром пороге 0.25 (первый проход `scan`).

Скорость та же (та же сеть YOLO26n, 2.4 млн параметров): на 1 потоке CPU Мака
13.5 мс/кадр `.pt`, **5.0 мс NCNN**. NCNN-экспорт проверен: те же цифры
приманок и поиска, что у `.pt`, до десятых.

Слабое место — Φ: пропуски на мелких дальних метках и смазе, иногда путает с
Ψ. Ошибки C на своих val-кадрах: `~/maze_dataset/reports/C_errors_own_val.jpg`.

## 4. Ошибки разметки в своём датасете

Модель C нашла 12 кадров, где разметка в Roboflow не совпадает ни с папкой
съёмки (имя файла `omega_/phi_/psi_`), ни с тем, что на кадре: Ω размечена как
phi, Φ как omega, Ψ как omega/phi. Просмотрены все — модель права, разметка
нет (`reports/label_suspects.jpg`, список — `reports/label_suspects.txt`).
Исправлено скриптом `fix_labels.py` во всех копиях датасета. `build_ds.py`
пересобирает `ds_own` из экспорта Roboflow — после него запускать
`fix_labels.py` снова, а лучше поправить эти 12 кадров в самом Roboflow.

## 5. Как поставить на робота

Файлы на Маке: `~/maze_dataset/models/maze_v26n_C.pt` и папка
`~/maze_dataset/models/maze_v26n_C_ncnn_model/`. На Pi их место —
`~/maze/models/` (рядом с `maze_v26n_B.pt`). Наблюдатель сам берёт NCNN-папку
рядом с `.pt` (`watch_logic.prefer_ncnn`).

Вместе с моделью на Pi нужны новые `victim_detect.py`, `watch_logic.py`,
`watch_proc.py` — без них B работает как раньше, а C без них будет
останавливаться на приманках классов H/S/U/letter.

Запуск с C: `MAZE_MODEL=C` перед командой запуска `nav.py`. Если всё хорошо —
поменять букву по умолчанию в `victim_detect.py` (`YOLO_MODEL_PATH`).

Проверить на поле до заезда: положить на стену несколько чужих букв (Q, O, U,
S, H, кириллицу) рядом с настоящими Φ/Ψ/Ω и проехать вдоль — в
`~/maze/detections` должны появиться кадры с рамками `letter`/`H`/`S`/`U`, а
остановок и миганий на них быть не должно. Эти кадры — лучший материал для
следующего дообучения: если C на чём-то ошибётся, его надо добавить в датасет.

## 8. Можно ли учить быстрее на Маке

Замер на 15% `ds_v2`, одна эпоха, M4 Pro (MPS):

| батч | подготовка картинок | кадров/с |
|---|---|---|
| 32 | в основном процессе (как сейчас) | 90 |
| 32 | 8 процессов | 77 |
| 64 | в основном процессе | 92 |
| 64 | 8 процессов | 81 |

Упор — в видеокарту: она занята на ~94%, подготовка картинок — 0.05 с из
0.37 с на батч. Отдельные процессы для картинок (ultralytics на MPS их
отключает, вернуть можно колбэком, см. `train_c2.py`) только мешают, батч 64 —
+2%, в шуме. Тихие вентиляторы — не простой: сеть маленькая, видеокарта
занята запуском множества мелких операций, а не тяжёлой математикой, и
греется мало. Настройки `train_v2.py` оставлены как есть.

## 9. C2: дообучение на исправленной разметке — не взято

C дообучена 25 эпох (`train_c2.py`, шаг 0.002, ранняя остановка на 15-й) на
`ds_v2` с исправленными 12 метками. На той же исправленной валидации: Φ 87.7%
(C 88.4), Ω 92.0 (92.7), Ψ 98.7 (98.7), цели 98.0 (100), приманки 0.08% (0).
Чуть хуже по всем пунктам — 12 меток на ~1000 слишком мало, а новый разогрев
шага сбивает уже хорошие веса. Для робота — **C**. Исправленная разметка
останется для следующего полного обучения.

## 10. Короткий путь у C и модель C3 (2026-10-12, день)

**Что нашлось.** Тест на камере Мака: Φ и Ψ с экрана телефона C назвала
`letter` (0.74–0.76). Причина — «короткий путь»: в синтетике (`ds_synth`) всё
нарисованное шрифтом было приманкой, а все настоящие Φ/Ψ/Ω — фото с камеры.
C выучила «нарисовано → приманка». Проверка: Φ/Ψ/Ω, нарисованные тем же
генератором, C назвала приманкой в **296 из 300**. Размер метки ни при чём: на
своих кадрах C узнаёт метку и при 80% кадра.

**Лечение.** `synth_letters.py` теперь умеет вклеивать и жертвы
(`VICTIM_P`): `ds_synth2` — 3061 кадр, половина вклеек — Φ/Ψ/Ω с разметкой
жертв. `ds_v3 = ds_v2 + ds_synth2`. C3 — C, дообученная на `ds_v3` 30 эпох в
Google Colab (T4, 1.2 ч; `~/maze_dataset/colab/train_c3_colab_v2.ipynb`,
результаты на Диске в `maze_colab/runs/C3_synthvict`).

| | B | C | **C3** |
|---|---|---|---|
| нарисованные Φ/Ψ/Ω (300) → жертва | 144 | 3 | **295** |
| приманки → жертва (ds_v3 val, 1595, порог 0.45) | — | 0.0% | 0.25% |
| незнакомые RCJ H/S/U (фото) | 31% | 0.0% | **0.0%** |
| свои кадры: Φ / Ψ / Ω / цели (из 50) | 45/49/48/50 | 45/50/47/50 | 45/50/46/50 |
| найдено на ds_v3 val: Φ / Ψ / Ω | — | 57 / 63 / 60% | **92 / 98 / 95%** |

Ошибки C3 на приманках — 4 из 1079 нарисованных букв, все «круглые»: Q → Ω
(0.60), повёрнутая 6 → Ω (0.73), D с чертой → Ω (0.47), перечёркнутая B → Ψ
(0.47) (`reports/C3_decoy_errors.jpg`). Q неприятна — на ней B ошибалась на
соревнованиях; если C3 на поле будет путать Q, добавить в синтетику больше
Q/O/6/D и дообучить.

NCNN-экспорт C3 проверен (те же цифры). Файлы: `~/maze_dataset/models/maze_v26n_C3.pt`
и `maze_v26n_C3_ncnn_model/`.

**Для робота — C3** (вместо C): `MAZE_MODEL=C3`. Перед заездом — тот же
тест на поле с чужими буквами (п. 5), плюс Φ/Ψ/Ω, распечатанные очень чётко.
