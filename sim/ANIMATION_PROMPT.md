## Задача
Сделать **очень подробную анимацию** того, как робот едет по полигону с горками и препятствиями — по данным уже существующего симулятора, где крутится настоящий `nav.py`.

## Что уже есть (изучи код сам, не верь на слово)
- `sim/maze_sim.py` — модель робота и поля:
  - подменяет железо (serial, RPi.GPIO, лента, камеры) и время (виртуальные часы, `nav.time`, `nav.wait_telem` = шаг модели 5 мс);
  - класс `World`: стены — прямоугольники в плане с высотой `z0..z1` (`World.walls`), рельеф — `World.pieces` (прямоугольник + функция высоты: горки, острова верхнего этажа, бугорки, кирпичи — низкие стены);
  - класс `Sim`: поза `x, y` (мм; x — восток, y — север), `theta` (° по часовой от севера), скорости колёс `vl, vr` (см/с), команда `cmd` (`M` — режим скорости, `T` — момент, то есть ассист), `pitch()`, `axle_heights()`, `crashes`, `max_pitch`, лидар 360 лучей раз в 0,1 с (`_scan`) → `walls.measure` и `corridor.corridor_points`;
  - `setup(sim)` готовит nav к прогону.
- `sim/run_scenarios.py` — сценарии `flat, bumps, ramp, brick, bigbump, two_ramps` (мир, потолок клеток, ожидаемые горки), прогоняет `nav.flood_fill_run` + `nav.return_to_start`, пишет лог в `sim/logs/<имя>.log`, проверяет карту. Запуск из корня проекта: `python3 sim/run_scenarios.py [имя]`.
- Что nav печатает и что полезно показать: `─── (x,y) N → E ───` (шаг маршрута), `→ кл.(x,y): R=есть(57т,160мм) L=нет(…) F=… → прямо/стоп (новая/известна/цель/дальше горка/не уверен)` (решение без остановки), `[odo] столбик …` (поправка пути), `препятствие #1 …`, `горка: pitch=…`, `ГОРКА ВВЕРХ/ВНИЗ`, `⛰ ГОРКА …`, `БАМПЕР`, `торможение с …`, `у стены`, `поворот …`, `[выр]` (доводка).
- Глобалы nav, которые можно читать (не менять): `_maze` (клетка → [N,E,S,W]: True стена / False проход / None), `_visited`, `_ramps`, `_edge_fixed`, `_blocked`, `level_of(cy)` (этаж; `LEVEL_STRIDE=1000` в cy). `nav._write_state(cx, cy, hdg, checkpoint, phase)` вызывается при каждом приезде в клетку — в симуляторе это заглушка, её удобно использовать как точку снимка карты.
